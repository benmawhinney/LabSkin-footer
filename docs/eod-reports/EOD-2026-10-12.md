## Issues Encountered & Solutions

- **Fluorescent animation did not mount on the homepage:** the new markup had a different root ID from the legacy preview. Switched to a panel-scoped root lookup and eager image loading on selection. Removed the scrubber/status dependency; verified the camera timeline advances while visible.
- **Mobile Mesh links overlaid the interaction surface:** the homepage Current-footer spacing selector also matched Mesh and overrode its 294px mobile reservation. Restricted the rule to the Current panel; verified the first nav link is below the 260px mesh canvas and the canvas receives the hit test.
- **Hidden browser tabs looked like broken animations:** visibility-aware rendering and CSS transitions were paused in backgrounded shared pages. Retested with a visible page rather than disabling that protection.
- **Initial full-thickness scaffold was too literal:** replaced stacked wireframe shelves with a translucent membrane and irregular triangular field. Reused the footer fragment shader, deformation logic and response timings, adapting projection and raycasting for the 3D scene. Verified the copied footer source differs only by exported shader/constants; the actual footer renderer was not replaced with the explainer renderer.
- **Sticky header obscured direct-scroll captures:** added a 120px scroll margin to the embed. Verified direct scrolling places its top clear of the existing sticky header.
- **Static assets bypass WordPress robots filters:** added `noindex, nofollow` to the explainer document itself and verified the served static document's meta tag.
- **Windows command routing/quoting interrupted checks:** used `npm.cmd`, noninteractive basic HTTP parsing, AWS CLI paging disabled, native Windows `tar.exe`, and guarded SSH/SCP commands. Failed command attempts did not replace live files. PHP lint ran remotely because local PHP is unavailable; first-party JavaScript syntax checks ran locally because the staging host has no Node runtime.
- **Staged whitespace gate flagged vendor shader strings:** removed trailing formatting whitespace only in the minified Three.js module, redeployed the matching file with a unique backup, and reverified shader compilation and the staged whitespace gate.
- **Existing menu URL issue found:** `/index.php/about-us/` returns 404, while `/about-us/` returns 200. This is outside the explainer integration and remains a menu/permalink follow-up; no menu data was rewritten during this task.
